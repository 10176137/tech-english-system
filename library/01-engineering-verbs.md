# 核心工程动词与动词短语库 (Engineering Verbs & Phrasal Verbs)

> 母语工程师的秘密：他们很少用生僻拉丁语大词，而是把最朴素的小动词搭配介词（短语动词）用到极致。

---

## 1. 部署、环境与服务生命周期

| 动词短语 | 含义 | 例句 |
| :--- | :--- | :--- |
| **spin up** | 启动/快速搭建 (环境/容器) | *“I'll spin up a new staging environment to reproduce the bug.”* |
| **tear down** | 销毁/拆除 (环境/容器) | *“We should tear down the idle instances to cut cloud costs.”* |
| **roll back** | 回滚 (代码/版本) | *“We hit a critical bug in production, let's roll back immediately.”* |
| **kick off** | 启动/开始 (任务/会议/构建) | *“Let's kick off the CI pipeline and see if all tests pass.”* |
| **deprecate** | 废弃 (接口/功能) | *“We plan to deprecate this v1 endpoint by the end of Q3.”* |

---

## 2. 问题排查与故障处理

| 动词短语 | 含义 | 例句 |
| :--- | :--- | :--- |
| **track down** | 追查/定位 (隐蔽Bug) | *“It took me all morning to track down where the memory leak came from.”* |
| **drill down (into)** | 深入钻研/下钻排查 | *“Let's drill down into the database logs to see the slow queries.”* |
| **work around** | 绕过/做临时规避 | *“The upstream API is down, so we implemented a quick work-around.”* |
| **rule out** | 排除 (某种可能性) | *“We can rule out network latency; it's definitely a locking issue.”* |
| **fall back on** | 降级/依赖备选方案 | *“If Redis is unavailable, the service will fall back on the local cache.”* |

---

## 3. 协作与敏捷敏捷流

| 动词短语 | 含义 | 例句 |
| :--- | :--- | :--- |
| **unblock** | 解除阻塞/让某人继续 | *“Could you approve this PR? It'll unblock the mobile team.”* |
| **sync with ... on ...** | 和某人对齐某事 | *“I'll sync with the QA team on the regression test cases.”* |
| **flesh out** | 丰富细节/细化需求 | *“We need to flesh out the edge cases before committing to the sprint.”* |
| **push back (on)** | 驳回/有理有据推掉 | *“We should push back on this deadline, given the technical complexity.”* |
| **piggyback on** | 顺路带上/顺便搭便车 | *“Can I piggyback a quick typo fix on your PR?”* |
