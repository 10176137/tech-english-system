# 敏捷站会场景剧本库 (Daily Standup Scenarios)

## 1. 黄金结构 (What I did + What I'm doing + Any Blockers)

### 模板 A：日常顺利平铺直述
> *"Morning everyone!  
> Yesterday, I wrapped up the **[feature/bug]** and **put up a PR**.  
> Today, I'm going to work on **[task]** and write some unit tests.  
> **No blockers at the moment**, but I might need a quick 5-minute sync with **[name]** later today."*

### 模板 B：存在阻塞与等待
> *"Morning Alex!  
> Yesterday, I was digging into the **[issue]**, but I'm currently **blocked on [dependency / third-party API / DB access]**.  
> Today, while waiting for that, I'll switch gears and pick up the ticket for **[secondary task]**."*

---

## 2. 应对追问的高频回血话术 (Handling Follow-ups)

* **没听清问题**：
  * *“Sorry, you broke up a little bit. Could you repeat that last part?”*（抱歉，你刚才声音卡了一下，能重复下最后那句吗？）
* **需要想几秒（争取时间）**：
  * *“That's a good question. Let me think for a second...”*（好问题，让我想一下……）
* **会后详聊（不占用站会时间）**：
  * *“I think that might take a few minutes to unpack. Let's take this offline after the standup.”*（我觉得展开讲可能要花几分钟，我们站会后线下单聊吧。）
